# The app's headless edits, each replayed natively in Rust (`kurven-cli app`)
# and held to what Swift's app (`KurvenApp`) wrote for the same line.
#
#   NAME DISTANCE LENGTH INPUT ARGS...
#
# INPUT is a bundle under inputs/, given to the app as its bare path; an
# argument @FILE is FILE in the script's own directory (a saved bundle or a
# baked drawing). `make.sh` runs the Swift app over every line and keeps each
# saved bundle's manifest and each drawing; scripts/check-web.sh runs the
# Rust app, requires every manifest byte for byte, and compares every drawing
# with `kurven-cli compare` at DISTANCE page units and LENGTH relative (the
# reference drawings' floor, crates/fixtures/references.txt). The wasm module
# under Node must write what native writes, byte for byte.
#
# Which path of App.swift a line takes is App.swift's rule: a painting flag
# (--add, --remove, --function, --undo, --redo, --axis, --light, --truncation,
# --hide, --drag, --relief, --dump, --inspector) or a pick with an edit runs
# the edits in order (`headlessPaint`); --save or --bake alone runs the levels,
# then the strokes, then a surface's fields (`headlessBundle`); --surface and
# --landscape open from the catalog.
